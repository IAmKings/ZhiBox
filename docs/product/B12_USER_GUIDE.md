# B12 用户指南：图谱、设置、备份与诊断（环境受限通过）

> B12 已在“高端+中端、缺低端”环境受限口径下通过（用户 2026-10-19 接受）；签名 RC 已构建/验签/clean install，未自动发布。本指南用于内部验收与用户操作。

## 1. 来源图谱 / 事件详情

1. 打开「来源」页，切到「图谱」tab。
2. 用顶部「全部来源 / 来源名」chips 过滤；列表按事件分页加载（每页 50，最多 200 条），点「加载更多」继续。
3. 事件卡显示标题/摘要/来源·文档/实体 chips（最多 8 个，+N 表示更多）。
4. 点事件卡进入详情：实体（名称/类型/描述）、owning chunk 原文与段号/字符位置、来源文档；系统返回键关闭详情。
5. 没有抽取数据时显示空态：开启 SAG 增强并在设置页「补抽取」后回来查看；SAG 未启用不影响普通文档检索。

## 2. 检索预算档位

设置 → SAG 增强 / LLM 末尾「检索预算档位」：
- 高（默认）：Kpool 500 / Kseed 50 / frontier 50 / Kcand 100 / Kevent 5 / Kout 10；
- 中：300/30/30/60/4/10；
- 低：150/20/20/40/3/10。
切换后对**下一次**检索/问答生效；低端设备建议低档以减少扫描/内存。

## 3. 备份 v3 / 导入

设置 → 备份与迁移：
- 导出：只含 ready 文档与受支持空间；**FTS 不导出（导入后从原文重建）**；含 SAG 事件/实体/SAG 向量/抽取任务；**聊天/问答记录、query trace、API Key 不导出**；本机 UI 提示状态（`ui_hint_*`，如引导条是否看过）不导出；
- 导入预览：显示备份格式 v1–v3 与计数；v1/v2 或 SAG 空包会提示“导入后可补抽取”；
- 恢复后原文文件不迁移；模型/空间依赖提示见预览与迁移卡。

## 4. 诊断 trace

设置 → 诊断：
- 显示检索/问答 trace 总数与最近 50 条按 mode 计数；
- 「导出脱敏 trace」写 JSON 到应用私有 filesDir/trace_exports/，仅 id/queryHash/mode/timingJson/degradedReason/createdAt，**不含正文/key**；
- 失败可读，可关闭后重试导出。

## 5. 隐私

- SAG 增强/问答生成默认关闭；默认禁网；首次联网问答需显式同意；
- API Key 存 Android Keystore，UI 只显示掩码；不写日志/备份；
- 备份不含聊天/trace/Key。

## 6. 已知限制

B12 设备矩阵缺 4–6GB 低端（用户接受环境受限）；PJZ110 为 signed RC clean install，K60U/K40 以 debug 做功能与性能验证；语义支持/首 token 等沿用 B11 限制。
