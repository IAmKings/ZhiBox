# ZhiBox UI 模块功能清单（v0.1.2 开发态）

- **生成日期**：2026-10-21
- **用途**：按 UI 模块盘点现有功能、状态、入口、关键交互与已知限制，作为 UI 模块优化任务的输入清单。
- **代码基线**：`master`（P1.4 完成后；v0.1.2 签名候选开发中）
- **状态图例**
  - ✅ **已实现**：代码 + 自动测试完成，已有真机/离线证据（UI 真机程度见备注）
  - 🧪 **部分验证**：代码完成，但仅部分设备/场景验证，或依赖 LLM key/人工抽检
  - ⚠️ **已知限制**：功能可用但存在明确边界/易用性问题
  - 🚧 **规划/未实现**：仅列入后续 UI 任务
- **说明**：本清单只描述 UI 能力与交互，不重复后端算法/数据契约；真实 Agent 质量仍以 `P1_4_QUALITY_EVAL_PLAN.md` 门禁为准，**不得把 offline/mock 结果当质量结论**。

## 3. 导入（UI-IMPORT）

### 3.1 文件导入
- [x] SAF 多选：`OpenMultipleDocuments`，MIME `*/*`，落盘前按扩展名白名单过滤。
- [x] 支持：txt/md/pdf/docx/pptx/xlsx/html/htm（页面/文案与实际解析器一致）。
- [x] 50MB 流式暂存上限；隐藏 `.part` 临时文件 + rename 原子写；路径穿越/重名/隐藏文件防护。
- [x] 暂存数量/文件列表；「全部导入」触发生产导入链路。
- [x] 导入任务卡：阶段、进度、错误、状态；进行中/最近任务分区；最近条数上限。
- [x] 批量结果「新导入 N / 已存在 M」。
- [x] 取消导入、失败重试、失败错误动作提示（模型/空间/OOM/解析）。
- [x] SAG 抽取汇总（完成/队列/进行中/失败/未索引）与失败提示。
- [x] PDF user-password：失败卡「输入 PDF 密码」→ 对话框 → 重试；密码不显示明文、不落库。
- [x] 网页 URL 导入：HTTPS-only/网络门禁/2MB/标题作为来源名；暂存 .txt + URL provenance。
- [x] OCR 开关在设置（默认开）；扫描件无文本层时逐页 OCR。
- [ ] ⚠️ 空态仍暴露 `files/import-staging/` 开发者路径，普通用户不可理解。
- [ ] ⚠️ 文件来源/文件名作为 source title，缺少重命名/来源分组。
- [ ] ⚠️ URL 输入在部分设备中文 IME 下体验一般；无粘贴/清空快捷。
- [ ] ⚠️ 任务卡错误动作需点「设置」跳转，缺少就地修复/逐任务重试。
- [ ] ⚠️ 扫描件 OCR 全页耗时较长；无进度以外的耗时预估。
- [ ] 🚧 无系统分享/Intent 导入入口。

**优化建议**：空态改为“选择文件/拖入/从分享导入”的任务化页面；增加来源重命名；逐任务重试；URL 输入补键盘类型、粘贴与示例；任务卡展示预计剩余/可取消。

**测试/证据**：SAF 真机选择（K60U）；URL 真实网络抓取；PDF 密码进程重启恢复；OCR 25 页真机；见 `docs/review/` 对应报告。

- [x] 统一 `ZhiBoxScreen` 顶栏/返回；统一 `LoadingState` / `EmptyState` / `ErrorState`。
- [x] 大部分错误可读（错误码+用户文案）；关键数据操作有确认。

- [ ] ⚠️ 无统一设计 token/间距规范文档；各屏 section 密度不一致。

- [ ] ⚠️ 键盘/IME 对 URL/别名/设置输入存在设备差异（中文输入法组合）。

## 12. 建议的 UI 优化任务优先级

| 优先级 | 模块 | 任务 | 验收建议 |
|---|---|---|---|
| P0 | Settings | 拆分为分组/二级页 + 搜索设置项 | 首屏可定位模型/LLM/诊断；长说明折叠 |
| P0 | Import | 空态任务化 + 来源重命名 + 逐任务重试 | 普通用户无需知道 `files/import-staging` |
| P0 | Home | KB 概览 + 最近导入/模型缺失提示 | 3 秒内知道下一步做什么 |
| P1 | Chat | 引用 chip 显示来源名/摘要、单条重试/复制、Agent 步骤折叠 | 长会话仍可读；引用一眼可辨 |
| P1 | Search | 高亮/来源筛选/分页；trace 默认开发入口 | 结果首屏聚焦正文与命中 |
| P1 | Sources | 搜索/筛选/批量删除/错误就地重试 | 大库可管理；删除有撤销 |
| P1 | Explore | 节点聚焦/邻居高亮、标签遮挡、图例/操作提示 | 200 事件仍可读；TalkBack 可替代 |
| P1 | Shared | 无障碍/字号/横屏/TalkBack 专项 + 稳定 Compose 测试环境 | 无阻断级可访问性问题；UI 回归可重复 |
| P2 | All | 新用户引导、空态插画、动画/骨架屏、分享/Intent 导入 | 首次使用路径完整 |
| P2 | Chat | 会话导出/分享、消息复制、真 Agent 质量评测后强化文案 | 不以未完成评测做宣传 |

## 13. 明确不纳入本清单的项

- 后端/检索/解析/LLM/Agent 算法质量本身（见对应 review 报告）。
- debug 实验屏的内部 benchmark 功能。
- 未实现的能力（图片/音视频/多模态、账号/云同步、RAG 插件/MCP 等）仅在未来 backlog，不伪装成已实现 UI。
