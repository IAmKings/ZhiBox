# B11 带引用问答：使用与隐私说明（开发中）

> 状态：B11 代码/自动门禁已落地；真实 20 条问答与 50 条支持率尚未在具备 LLM key 的设备上跑完。
> 本说明面向用户与发布前验收；门禁通过前不要把 B11 标为正式发布。

## 1. 使用前提

1. 在「设置 → 联网问答」保存 OpenAI-compatible 配置（完整表单在「高级与诊断 → SAG 增强 / LLM」）：
   - Base URL 必须 `https://`；
   - model 为服务端支持的模型 ID；
   - API Key 保存到 Android Keystore（SharedPreferences 只存密文/iv）。
2. 打开「问答生成」与「允许联网」，并完成首次联网同意。
3. 未配置/禁网/关闭问答时：检索、图谱等离线功能不受影响；问答入口会给出可读提示，不会发起网络请求。

## 2. 单轮行为（P0）

- 每次问答只使用**本轮 query + 本轮检索证据**；不注入历史消息，因此不会把上一轮内容带到下一问；
- 会话/消息/引用持久化，可在最近会话中重开查看；历史仅展示，不自动作为上下文；
- 引用格式 `[S1]…[Sn]`，映射到本次证据 chunk；点击引用 chip 打开证据原文；
- 无证据：直接回复「资料不足，无法回答」，不调用 LLM；
- 引用校验：只接受 `[S#] ⊆ 本次证据`；非法 token 替换为 `[未通过证据校验]`，无有效引用/存在未引用断言句时醒目提示；
- 支持停止/重试；停止的半成品不写入最终 assistant 消息；重试复用同一 query/会话，不重复追加 user 消息。

## 3. 发送了什么

只发送完成任务所需的最小数据到用户配置的 LLM endpoint：

- 本轮问题文本；
- 最多 10 条证据 chunk 的**正文**（每条最多 1200 字）及文档/来源标题、段号等定位元数据；
- 不发送原文件路径、完整知识库、API Key、设备标识；请求/响应正文不写日志；
- 提示词要求只使用证据、逐句标注引用、证据不足拒答；证据文本被当作数据而非指令。

## 4. 隐私与数据生命周期

- API Key：Android Keystore 加密，不入日志/备份/导出；UI 只显示掩码。
- Chat 会话/消息/引用：Room 本地保存；**P0 备份默认不含 chat/query_trace**（隐私/体积）。
- QA trace：仅 queryHash、耗时、证据数、引用状态、降级原因，保留最近 50 条，无正文。
- 禁网开关为总开关：Provider 在发请求前实时检查；禁网时零网络请求。

## 5. 当前已知限制

- 引用有效性目前是 ID 级 + 逐句未引用规则；**语义支持率**需 50 条人工/LLM judge 抽样（B11 门禁未跑）。
- source scope 支持来源多选并保存；Chat 的检索模式可选自动/混合/fast/multi。
- TLS mock 覆盖整包 SSE；真实 chunked 逐块/中途断流与首 token SLO 仍需真机验收。
- B11 真实 LLM 20 问答/50 支持率依赖有效 key；未完成前 B11 保持 🟡 部分完成。
