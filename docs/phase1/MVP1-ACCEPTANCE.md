### W4+ 已交付（2026-10-17，K60U 回环验证 PASS）

1. **切换模型后旧数据自动重嵌入**（§9.1-7 增强）：当前语义为空间隔离+显式切回/重导入；
   自动后台重嵌入因数据量大时发热与阻塞风险（实测嵌入占导入时长 60-90%），明确列为后期
   优化项而非当前版本实现。实现位：EmbeddingRuntime 切换事件 → WorkManager 后台批量重嵌入
   （分块限速 + 电量/温度门槛）。
2. **向量库跨设备迁移的模型依赖校验**（前瞻设计，导出/导入功能落地时实现）：
   - 导出包必须附带 embedding_meta（空间注册表）+ 模型需求清单（fileName + sha256 + accelerator）；
   - 导入端校验：模型在位且后端匹配（CPU 向量 arm64 间逐位一致，直接可用，无需重建）→ 正常导入；
     模型缺失 → **导入向导提示"需要下载模型 X"并联动模型商店下载入口**（当前拒绝提示只列空间清单，
     缺下载引导——补）；
   - GPU/NPU 空间跨设备：向量按 GPU 家族聚簇（Adreno/Mali 不同簇），跨家族导入应提示
     "该空间向量与本机 GPU 不兼容，建议重嵌入"或直接拒绝；
   - 依赖机制全部已就绪：spaceId 指纹（含 accelerator）、ModelCatalog（fileName→url/sha）、
     SharedModelStore（下载+校验）。
